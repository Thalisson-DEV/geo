# Inventário de telas do redesign

Gerado em 2026-11-20 a partir de `frontend/src/app/app.routes.ts` (branch `redesign/full`) por script (TypeScript compiler API + regex). Contagens são automáticas; tipo e prioridade são heurísticas revisáveis.

## Como ler

- **Uma linha por rota** com componente (redirects ignorados). Rotas geradas por `.map()`/`.flatMap()` foram expandidas. Rotas que reutilizam o mesmo componente repetem as contagens.
- **Módulo** = pasta `features/<módulo>` do componente (não o prefixo da URL; ex.: `/admin/cadastros/contratos` aparece em Contrato).
- **Componentes @geo/ui**: elementos `<geo-*>` e diretivas de atributo do design system (`[geoCell]`, `[geoRowActions]`, `[geoListShortcuts]`, `[geoTabPanel]`, `[geoRowDetail]`, `[geoValorAnimado]`) encontrados no template do componente (inline ou `templateUrl`).
- **PrimeNG direto**: imports `primeng/*` no `.ts` do componente roteado (deveriam estar só dentro do `@geo/ui`).
- **Dívidas visuais** no formato `ng-deep/!important/hex/rgb/ngIf-ngFor/pi (total)`, contadas no `.ts`, no `templateUrl` e nos `styleUrl(s)` **do próprio componente**:
  - `::ng-deep` e `!important`: ocorrências literais;
  - hex: `#rgb`, `#rgba`, `#rrggbb`, `#rrggbbaa` precedidos de `:` `(` `,` aspas ou espaço após `:` — referências de template (`#dt`) não contam;
  - rgb: `rgb(`/`rgba(`/`hsl(`/`hsla(` seguidos de número (literal; `rgb(var(--x))` não conta);
  - ngIf/ngFor: `*ngIf` e `*ngFor`;
  - pi: ocorrências de `pi pi-` (PrimeIcons).
  - "+N em subcomp." = soma das mesmas dívidas nos componentes de `features/` importados pelo componente (até 3 níveis), para dimensionar a tela inteira.
- **Endpoints**: chamadas `this.<service>.<método>(` no componente (e classes base), resolvidas até `HttpClient`/`BaseService` (`getList`=GET, `getOne`=GET `/{id}`, `createSync`=POST, `updateSync`=PUT `/{id}`, `patchSync`=PATCH, `deleteSync`=DELETE), inclusive via stores que delegam a services. Caminhos relativos a `/api` (o `environment.apiUrl`). Parâmetros de caminho normalizados para `{id}`. "+N via subcomponentes" = endpoints adicionais chamados por subcomponentes da feature.
- **Prioridade**: P1 = listagens, formulários centrais e dashboards de módulo; P3 = cadastros auxiliares, configurações e manuais; P2 = demais (detalhes, relatórios, kanban/calendário, telas secundárias).
